这个版本是 Godot 工程的完整版，目前还没有 Web 构建产物，所以暂时不能在浏览器里运行。

桌面端可以直接运行打包好的 exe。

把它变成可在线玩的步骤

  1. 用 Godot 打开 01-原版-Godot 工程
  2. 菜单 项目 → 导出，选中已有的 Web 预设
  3. 导出路径保持 build/index.html，点「导出项目」
  4. 把 build/ 里的全部文件复制到本站的 play/original/ 目录
  5. 重新部署，这个页面就会自动变成游戏入口
